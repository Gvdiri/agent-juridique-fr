# Journal des décisions

> Une entrée par décision arrêtée. On n'efface jamais une entrée : une décision remise
> en cause donne une nouvelle entrée qui renvoie à l'ancienne.

## Modèle d'entrée

### AAAA-MM-JJ — [la question, en une ligne]

- **Options étudiées** : A, B, C
- **Décision** : …
- **Pourquoi** : …
- **Sources** : URL + date de consultation, avec leur marqueur
- **Ce qui l'invaliderait** : le fait nouveau qui obligerait à revenir dessus
